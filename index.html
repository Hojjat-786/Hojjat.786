🔎 بررسی Metadata NFT

فایل JSON مربوط به NFT خود را وارد کن و فیلدهای مهم آن را بررسی کن.

۱. وارد کردن Metadata

اطلاعات همین‌جا در مرورگر بررسی می‌شود؛ این صفحه چیزی را به بلاک‌چین ارسال نمی‌کند.

۲. بارگذاری JSON از لینک (اختیاری)

بعضی سایت‌ها به‌دلیل محدودیت CORS اجازه بارگذاری مستقیم نمی‌دهند؛ در آن صورت JSON را در کادر بالا کپی کن.

۳. نتیجه بررسی

هنوز چیزی بررسی نشده است.

ابزار ساده و آزمایشی برای بررسی اولیه Metadata؛ نتیجه آن تضمین‌کننده پذیرش NFT در همه بازارها نیست.
